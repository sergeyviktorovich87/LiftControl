# Лифт Контроль

Рабочая система лифтовой организации. Веб-панель и Android используют общий API для заявок, дежурств, объектов, ТО, чата, заданий и медиаматериалов.

Кандидатная сборка, проверенная в CI: панель/API **0.11** и Android **0.6.0 beta**, сборка **2061**. Приёмка на рабочем VPS и телефоне ещё требуется. Исходники, контрольные суммы и результаты проверок указаны в [паспорте выпуска](RELEASE.md).

| Каталог | Что в нём |
| --- | --- |
| [`backend/`](backend/) | Django API, модели и миграции. PostgreSQL на VPS, SQLite для локальных проверок. |
| [`web/`](web/) | Веб-панель React/Vite. Готовые ресурсы отдаёт Django. |
| [`mobile/`](mobile/) | Android-клиент Flutter, локальная очередь и системные уведомления. |
| [`deploy/`](deploy/) | Установка, обновление, HTTPS и резервирование. |
| [`tests/`](tests/) и [`.github/workflows/`](.github/workflows/) | Проверки установки, публикации APK и сборок. |
| [`docs/`](docs/) | Архитектура, правила работы, план и журнал решений. |
