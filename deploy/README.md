# Установка и обслуживание LiftControl

Для существующей панели 0.8–0.11 используйте [инструкцию обновления на 0.13.3](offline/UPDATE.md). Выданные архив панели и APK проверяются по [паспорту выпуска](../RELEASE.md).

| Каталог | Задача |
| --- | --- |
| [`offline/`](offline/) | Компактный пакет обновления. Перенос медиа и архив базы с файлами. |
| [`infra/`](infra/) | Базовая настройка Ubuntu и PostgreSQL, диагностика сервера и резервирование ролей. |
| [`public/`](public/) | Настройка HTTPS и проверка продления сертификата. |
| [`api/`](api/) | Compose API, настройка FCM, публикация APK и инструкции предыдущих выпусков. |
| [`web/`](web/) | Историческое описание веб-пилота. Актуальный запуск панели описан в [локальной инструкции](../docs/FIRST_RUN.md). |

Действующая установка использует `/opt/liftcontrol/`. APK помещаются в `/opt/liftcontrol/updates/android/`. Медиа и полные архивы базы с файлами находятся в `/srv/liftcontrol-data/`.

Перед обновлением проверьте версию API, место на диске и резервную копию. На новом сервере сначала подготовьте инфраструктуру и проверенный экземпляр приложения. Восстановление базы и медиа сначала проверьте на отдельной установке. Секреты и рабочие архивы храните вне репозитория.
