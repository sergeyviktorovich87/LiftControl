# Развёртывание LiftControl

Этот каталог предназначен для автоматической установки, обновления и восстановления LiftControl на сервере.

## Текущее состояние

Каталог подготовлен. Готовый установщик **ещё не реализован** — никакие команды из этой папки пока не запускают развёртывание.

## Целевая инфраструктура

- Сервер: Ubuntu 24.04 LTS.
- Приложение: Django REST API (папка `backend/`), React/Vite (папка `web/`), мобильный клиент Flutter (папка `mobile/`).
- База: PostgreSQL в Docker Compose на сервере; SQLite допускается только для локальной разработки.
- Docker Engine + Docker Compose, SSH с ключами, UFW, логи с ротацией.
- Тестовый доступ без публичного HTTP с паролями: через защищённый туннель/VPN; публичный HTTPS — при готовности к эксплуатации.

## План автоматизации

1. `ansible/` — воспроизводимая, повторно запускаемая настройка Ubuntu и базовой защиты.
2. `compose/` — декларативные конфигурации приложения, PostgreSQL и сетей Docker.
3. `scripts/` — проверки готовности, развертывание, обновление, резервное копирование и восстановление.
4. Отдельные режимы: чистая установка, обновление без потери данных, восстановление из копии.
5. Предварительные проверки: права доступа, ресурсы, версии, состояние резервных копий и наличие секретов.
6. Диагностические логи установщика и сервисов без паролей, токенов и приватных ключей.

## Безопасность данных

- **Никогда не коммитить:** `.env` с секретами, SSH-ключи, пароли PostgreSQL, резервные копии БД, пользовательские документы и фотографии.
- Пароли генерировать на сервере, передавать через защищённые файлы/секреты контейнеров.
- PostgreSQL не публиковать на публичном интерфейсе.
- Перед опасными миграциями делать внешние резервные копии и проверять восстановление.
- Переходы конфигурации, изменение SSH и UFW проводить с проверкой сохранения административного доступа.

## Что понадобится при переносе

Чистый VPS с Ubuntu, доступ по SSH, код из репозитория и, при восстановлении существующей организации, резервные копии базы и файлов.

> Действующая инфраструктура на VPS пока настроена вручную. Перед автоматизацией необходимо сопоставить её настройки с кодом репозитория и не переносить серверные секреты в Git.
