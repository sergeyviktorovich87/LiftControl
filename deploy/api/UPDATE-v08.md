# LiftControl 0.8 / Android 0.3.0

## Установка владельцем

1. Скачать и распаковать `LiftControl-v0.8-amd64.zip` на существующем сервере.
2. Выполнить из папки распакованного релиза:

```bash
sudo bash update-panel.sh
```

Установщик проверяет контрольные суммы, делает проверенную резервную копию PostgreSQL, применяет добавочную миграцию 0008 и проверяет API 0.8. Существующие аккаунты, лифты, заявки, фото, графики и настройки FCM сохраняются. Импорт данных и очистка базы не выполняются. Внутреннее имя образа `liftcontrol-api:0.6` сохранено ради совместимости Compose.

3. Установить `LiftControl-Android-0.3.0-beta-arm64.apk` поверх 0.2.x. Сертификат подписи проверяется при сборке. Для первого перехода со старой 0.1 требуется сохранить локальные черновики, удалить старую beta и установить новую; серверные данные остаются.
4. Перезагрузить вкладку панели. Для обновлений APK через профиль опубликовать содержимое Android ZIP через прежний `publish-update.py --android-release ПАПКА`.

## Изменения

- Быстрый чат в шапке панели и APK; фотографии JPEG/PNG/WebP и видео MP4/MOV/WebM. Одно сообщение: до пяти вложений, всего до 20 МБ; фото до 10 МБ, видео до трёх минут. Существующий предел NGINX 21 МБ достаточен. Файлы хранятся закрыто; скачивание и Range-запросы видео проверяют доступ к организации. Фотографии перекодируются с удалением EXIF, видео проверяет ffprobe в образе сервера. Имя файла и объявленный браузером MIME не заменяют проверку содержимого.
- Приоритет «Застревание». В Android отдельный канал высокой важности, собственный сигнал и вибрация. Раздельные категории обычных, срочных заявок, застреваний, изменений статусов и личных заданий. В профиле можно выбрать категории для текущей организации; звуком и вибрацией каналов управляют настройки Android. Браузер использует системные возможности Web Push.
- «Доп. задание» / «Личные задания». Руководитель или диспетчер назначает механику задачу с описанием, необязательным лифтом и сроком. Задание видно исполнителю и руководителям; коллеги не могут читать, принимать или менять его по ID. Принятие, комментарий, фотоотчёт, завершение с результатом и отмена с причиной сохраняются в истории. Личные задания не входят в общие заявки и общую историю лифта. Push о назначении адресуется исполнителю, о результате — создателю, с повторной проверкой доступа при отправке.
- У администратора убрана кнопка запроса подмены; текущий дежурный и его смена остаются видны.
- В общей библиотеке появилась кнопка «Редактировать»: название, производитель, модель и необязательная замена PDF. Предыдущие сведения и файл остаются в ревизии; устаревшая форма не перезаписывает более новое изменение. Автоматический подбор документации в карточках лифтов сохранён. Редактор страниц PDF в этот выпуск не входит.
- Диагностические журналы сохранены, без текстов чата, файлов, паролей и ключей. При выходе очищаются приватные временные файлы APK. Запоздалые ответы предыдущей организации не подменяют активные данные.

## Проверка на телефоне

- Открыть чат кнопкой возле обновления, отправить фото из камеры/галереи и короткое видео, просмотреть с другого аккаунта той же организации.
- Администратором выдать личное задание; исполнителем принять, приложить фото и завершить. Другой механик не должен видеть задание.
- В профиле открыть категории уведомлений и проверить отдельный сигнал застревания. Это локальная проверка звука; доставку с VPS проверяют новой заявкой «Застревание» при погашенном экране.
- В библиотеке изменить сведения документа и при необходимости заменить PDF. Проверить автоматический подбор для лифта.

## Что требуется глобально

Для реальной доставки APK-пушей остаётся однократная настройка Firebase, описанная в `deploy/api/UPDATE-v07.md`; новый проект Firebase не требуется, если FCM уже подключён. Локальная проверка звука не подтверждает доставку. Перед распространением сотрудникам нужен постоянный защищённый ключ подписи вместо временного CI-кэша, постоянный адрес HTTPS и резервные копии вне VPS. Установка этой версии не открывает новые порты и не меняет домен.

Протоколы реализации: [каналы Android](https://developer.android.com/develop/ui/compose/notifications/channels), [FCM Android](https://firebase.google.com/docs/cloud-messaging/android/receive-messages), [ffprobe](https://www.ffmpeg.org/ffprobe.html).
