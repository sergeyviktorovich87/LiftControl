# LiftControl 0.6 — безопасное исправление списка сотрудников

Этот пакет предназначен **только для уже установленной 0.6**. Не использовать для установки с нуля.
Включает новую форму «Настройки → Добавить сотрудника», синхронное создание логина/карточки/членства, улучшенную форму Django Admin. Для уже созданного аккаунта можно выбрать существующую карточку механика без её дублирования.

## Безопасность

- Скрипт `patch-v06-safe.sh` проверяет наличие установленной 0.6, создаёт PostgreSQL backup, сохраняет предыдущий образ Docker для отката и не меняет конфигурацию публичных портов.
- В отличие от `update-v06.sh`, **не вызывает `import_megapolis`, `--replace-work-data` и не очищает рабочие данные**. Фотографии и записи остаются в тех же томах.
- Применяет стандартные миграции (для этого патча новых миграций нет), проверяет API и доступность обработчика создания сотрудников.
- На ошибке пытается вернуть предыдущий образ; если изменена база, восстанавливает проверенную копию PostgreSQL, а при неудаче восстановления оставляет API остановленным.

## Обновление существующей 0.6

1. Откройте GitHub Actions → успешную сборку «Build downloadable LiftControl API image» для ветки `feature/android-client` после включения этого изменения.
2. Скачайте приватный артефакт `LiftControl-v0.6-amd64`, загрузите ZIP на VPS и распакуйте в отдельную папку. Не загружайте через общедоступную папку сайта.
3. В терминале VPS перейдите в распакованную папку и выполните:

```bash
sha256sum -c RELEASE.sha256
sudo bash patch-v06-safe.sh
```

Нужны Docker и рабочие compose-файлы в `/opt/liftcontrol`, права sudo, свободное место для образа и резервной копии. Скрипт временно остановит API и отправитель push. Он не меняет HTTPS или внешний адрес.

## Как пользоваться

- **Новый человек:** Настройки → Добавить сотрудника → «Сотрудник с логином и паролем». Укажите ФИО, логин, надёжный пароль, роль. Карточка появится в «Механики», логин — в Django Admin, доступ — в выбранной организации.
- **Механик из импорта без аккаунта:** выберите существующую карточку, затем задайте логин и пароль. Закреплённые лифты останутся на этой карточке.
- **Карточка без доступа:** выберите «Только карточка (без входа)».
- **Существующий аккаунт Django, например НиколаиА:** не создавайте новый логин. Суперадминистратор открывает Django Admin → Пользователи → этот пользователь → «Доступ к организациям», добавляет членство с нужной компанией, ролью и свободной карточкой. Альтернатива для человека, уже имеющего доступ к другой компании, — одноразовое приглашение.

Привязка по одному совпадению фамилии намеренно не выполняется: можно выдать доступ не тому человеку. Вход по одной учётной записи в нескольких организациях поддерживается.

## Что требуется от администратора

На этапе установки — загрузить архив на VPS, запустить две команды, проверить экран «Механики» и вход тестового пользователя. Далее — один раз связать старые аккаунты с правильными карточками и выдавать доступ новым людям уже из интерфейса. Пароли не отправлять в общий чат и не сохранять в диагностические логи.
