# Обновление API для Android 0.1 beta

Дополнение к установленной 0.6: вход и отзывные сеансы устройств, ограничение попыток входа и серверное время организации. Рабочая база, учётные записи, роли, лифты и история сохраняются. Домен, порты и сертификаты этим обновлением не настраиваются.

1. Скачайте свежий артефакт `LiftControl-v0.6-amd64` из **Build downloadable LiftControl API image** именно ветки `feature/android-client`.
2. Загрузите архив на VPS и распакуйте в отдельную папку. Пример, если имя файла на сервере такое же:

```bash
mkdir -p /home/liftadmin/update-android
python3 -m zipfile -e /home/liftadmin/LiftControl-v0.6-amd64.zip /home/liftadmin/update-android
sudo bash /home/liftadmin/update-android/update-android.sh
```

Запускайте `update-android.sh`. Он проверяет контрольные суммы, делает `pg_dump`, добавляет таблицы, выдаёт runtime-роли доступ к ним и перезапускает API/существующий push-worker. Повторный импорт «Мегаполиса» не запускается. Снимок базы и ссылка на прежний образ сохраняются в `/opt/liftcontrol/backups/before-android-*`. При ошибке возвращается предыдущий образ; добавленные таблицы остаются, рабочие записи не переписываются.

Проверка на сервере:

```bash
curl --fail --silent http://127.0.0.1:18080/api/health/
```

Ответ должен содержать `"android_api":1` (порядок полей и пробелы могут отличаться).

В приложении укажите домен с HTTPS. До настройки домена используйте существующий SSH-туннель телефона: локальный порт `18081` → сервер `127.0.0.1:18080`; адрес приложения `http://127.0.0.1:18081`. Публичный IP и открытие порта 18080 не требуются.
