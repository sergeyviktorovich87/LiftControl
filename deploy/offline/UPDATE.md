# LiftControl 0.10 / Android 0.5.0 beta

Сейчас от администратора требуется один раз обновить панель и установить APK 0.5.0 поверх старого приложения. Удалять приложение перед установкой не нужно.

## Панель

Загрузите LiftControl-v0.10-update.zip на сервер. В папке с архивом выполните:

```bash
unzip -o LiftControl-v0.10-update.zip
sudo bash LiftControl-v0.10-update/update-panel.sh
```

Пакет подходит для установленной панели 0.8, 0.9 или 0.10. До обновления сохраняются образ и резервная копия базы. Установщик подключает папку обновлений к API только для чтения. Новые зависимости скачивать не требуется. Данные организаций и заявок сохраняются.

## Все дальнейшие обновления Android

Постоянная папка на сервере:

```text
/opt/liftcontrol/updates/android/
```

Загружайте туда готовый подписанный APK через вашу программу передачи файлов. Имя может быть любым; удобно сохранять номер версии в имени. ZIP и файлы панели в эту папку не кладите. JSON и команда публикации не требуются.

На компьютере приложение собирается с прежней подписью, тем же идентификатором приложения и увеличенным versionCode. Изменение имени файла или текста версии не делает старую сборку обновлением.

После завершения загрузки сервер сам читает версию и SHA-256 из APK. Из нескольких APK выбирается сборка с наибольшим versionCode. При открытии и возврате в приложение проверяется сервер. Если установленная сборка старее, появляется окно «Доступно обновление» с кнопками «Обновить» и «Позже». После «Позже» повторное предложение появится при следующем открытии. Если обновления нет, окна нет. Если связи нет, работа с локальными данными продолжается без окна ошибки обновления.

При нажатии «Обновить» приложение загружает конкретный файл, проверяет размер, SHA-256, идентификатор, увеличение версии и прежнюю подпись. Установку подтверждает Android. При первом обновлении Android может попросить разрешить установку из LiftControl.

Недокачанные и чужие APK не публикуются. Для загрузки файлу нужны права чтения (обычно программа передачи ставит 0644). Можно загружать под временным именем .part и после окончания переименовать в .apk. Сохраняйте хотя бы предыдущий APK до завершения обновления команды.

От администратора при последующих выпусках требуется только положить новый APK в указанную папку. Сотрудникам — открыть приложение и подтвердить обновление.

## Уведомления

Регистрация телефона выполняется автоматически после входа, при возврате в приложение и обновлении токена. Ручной подписки телефона нет. Разрешение Android выдаёт сам владелец телефона один раз. Блок категорий удалён из панели и приложения. Настройка звука доступна в системных настройках Android.

Firebase должен быть один раз настроен на сервере: публичная конфигурация клиента и закрытый сервисный ключ для отправки. При отсутствии этой настройки доставка push в фоне ещё не работает; приложение показывает её действительный статус. Закрытый ключ не хранится в APK.

## Фото и диагностика

Фото из галереи и камеры Android уменьшаются до 1920 пикселей по большей стороне, качество JPEG 78. В панели фото сжимаются перед отправкой в чате, заявках и заданиях; маленькие файлы до 300 КБ и видео не перекодируются. Видео отправляется по прежним ограничениям. Логи beta остаются включены; добавлены события проверки, предложения и установки обновления. Пароли, токены и содержимое фото в логи не пишутся.
