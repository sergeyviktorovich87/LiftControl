# LiftControl Panel V1

Первая версия единой веб-панели LiftControl.

## Что уже работает

- единый интерфейс LiftControl;
- три режима: Руководитель, Диспетчер, Администратор;
- отдельное меню и главный экран для каждой роли;
- данные из текущего Django API: объекты, лифты, заявки, сотрудники, ТО;
- разделы Объекты, Лифты, Заявки, ТО, Механики, Журнал, Отчёты;
- оперативный экран диспетчера;
- создание новой заявки через `POST /api/tickets/`;
- индикация связи с Django API;
- адаптивный интерфейс для небольших экранов;
- схема оперативной карты как временная заглушка до подключения реальной карты/GPS.

## Важно

Переключатель роли в V1 тестовый. Настоящие учётные записи, JWT и права доступа будут подключены отдельным этапом.

## Запуск

```powershell
git fetch origin
git switch feature/panel-v1

cd web
npm.cmd install
npm.cmd run dev
```

Django API должен быть запущен на `http://127.0.0.1:8000/api`.

Из корня репозитория backend запускается отдельно:

```powershell
cd backend
.\.venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
```
