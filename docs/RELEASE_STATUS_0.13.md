## Подписанный Android

Выпущен [APK 0.13.0 beta ARM64](https://github.com/sergeyviktorovich87/LiftControl/releases/tag/android-v0.13.0-beta.1.1), сборка `5111`, из коммита `d3f244801e29d7a95370e2bcb14eaac363ebc6a7`. [Сборка и подпись](https://github.com/sergeyviktorovich87/LiftControl/actions/runs/44251599326) прошли Flutter analyze, 40 модульных и виджетных тестов, сборку release и проверку APK. Сертификат прежней beta восстановлен из кэша исходной ветки и совпадает с сертификатом APK 0.6.0, сборки `2061`. Идентификатор пакета остался `ru.liftcontrol.app.beta`; диагностические логи включены.

Скачанный APK независимо проверен Android Build Tools 37.0.0: подпись v2 действительна, версия `0.13.0`, минимальный Android API `24`, целевой API `36`, ARM64, release без `debuggable`. Контрольная сумма APK: `cac11dfd0203e5fabb5969646a6611365aa4daed6ddae8badfdfcd467bb2685b`. Имена локальной SQLite-базы, её версия, таблицы и ключи шифрования совместимы с прежней beta; проверка установки с сохранением реальной очереди остаётся пунктом приёмки на телефоне.

Подготовлен серверный комплект `LiftControl-Android-0.13.0-update.zip` через `package-android-update.py`. Проверены все его контрольные суммы, публикация реального подписанного APK во временный каталог и повторная публикация без дубля. Внутри есть подписанный APK, метаданные и `publish-android.sh`. Сам VPS этой сборкой не изменялся.

В сценарии Android-эмулятора обновлён выбор тёмной темы: вместо удалённого переключателя тест выбирает пункт «Тёмная» в списке «Тема оформления». Повтор остановился на скачивании Gradle: анонимный GitHub asset API вернул 403. Для Gradle и Kotlin добавлены основные официальные источники и резервный GitHub API с теми же закреплёнными SHA-256. Четыре Python-теста проверяют отказ при неверной сумме, сетевой резерв и очистку частичного файла; реальные архивы и JAR скачаны и проверены. Код, включённый в выпущенный APK, этими изменениями не менялся.

**[Итоговый прогон Android](https://github.com/sergeyviktorovich87/LiftControl/actions/runs/44253749748) завершился успешно.** На коммите `daa41b99492afde97c9283c916a3c6505cc5323a` прошли анализ, 40 тестов Flutter, четыре теста загрузчика, debug-сборка и сквозной сценарий Android 35 с Django. Проверены сохранение зашифрованной очереди и фото/видео при перезапуске без сети, потеря ответа и идемпотентный повтор, переключение двух организаций, создание сотрудника администратором, личные задания, медиа и выход с отзывом сессий. Серверная проверка сохранившегося состояния завершилась `ANDROID TO DJANGO VERIFIED`. От `d3f2448` до этого коммита менялись только тесты и подготовка инструментов сборки; прикладные исходники выпущенного APK остались теми же.

Для следующих APK защищённого workflow минимальный код версии поднят выше выпущенного `5111`, чтобы будущая сборка не была принята за понижение версии. Это проверяется перед публикацией.

[Свежая проверка Web/API от 18 ноября](https://github.com/sergeyviktorovich87/LiftControl/actions/runs/44253749745) завершилась успешно: 151 тест на SQLite и 151 на PostgreSQL 18, проверка миграций и непривилегированной роли БД, восстановление медиа, браузерные сценарии и Docker smoke build с сохранением медиа. Это не заменяет приёмку обновления на рабочем VPS.

## Приёмка и оставшиеся задачи

- Подписанный Android готов. Постоянное защищённое хранение ключа вместо старого кэша остаётся однократной настройкой владельца по [инструкции подписи](ANDROID_SIGNING.md).
- На стенде проверить Docker-установку, повтор запуска и восстановление базы с файлами. На Samsung и Honor проверить установку поверх старого APK, разрешение ОС, работу очереди после перезапуска, кэш и FCM при спящем экране.
- Остаются фоновый собственный Push в Doze, подтверждение доставки на устройство, тихие часы и действия из Android-шторки. Центр уведомлений сейчас хранит серверные события и прочтение.
- В наладке остаются вложения чата и потребностей, общий чат наладчиков организации, запрос нового объекта внешним специалистом и принудительная смена временного пароля. В действующем чате объекта есть текст и локальная очередь.
- В общем чате остаются личные диалоги и управляемые группы. Подробные требования сохранены в [плане 0.12](RELEASE_PLAN_0.12.md) и [плане 0.13](RELEASE_PLAN_0.13.md).
- Бланк сверён с предоставленным Excel и справочным приложением Б ГОСТ Р 55964-2022. Печатную форму принимает ответственный за журнал. [Стандарт](https://protect.gost.ru/gost/details/09996234-8757-4156-a8bc-5fe02e7a4b48)
