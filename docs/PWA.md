# PWA — Лифт Контроль (тестовая ветка)
Одна React-панель, один backend, один Service Worker. Android APK остаётся независимым клиентом. Установка: Настройки → Приложение Лифт Контроль; либо меню браузера. На iPhone/iPad — Safari → Поделиться → На экран «Домой». Требуется действующий доверенный HTTPS; IP с доверенным сертификатом допустим, доступность установки зависит от браузера.

Нет нового кеша бизнес-данных. Worker перехватывает только GET-навигацию на / и /login/ с того же origin, при сетевой ошибке возвращает нейтральную страницу 503. API и документы не перехватываются. Не сохраняются заявки для отправки позже. Существующий Web Push остаётся без изменений; поддержка и звуки зависят от ОС, браузера и существующих серверных настроек. Проверять отдельно реальной тестовой заявкой. При установленных APK и PWA возможны два уведомления.

Логи: Настройки → Диагностические логи, события pwa/worker, pwa/install, pwa/connection. Не содержат URL с параметрами, текста заявок, паролей или токенов. Логи остаются в памяти текущей сессии.

Проверки: `node --test web/tests/pwa-worker.test.cjs`, `python manage.py test core.test_pwa` из backend, сборка Vite с base /static/web/. После развёртывания: Chrome/Edge desktop, Chrome Android, Safari iOS, вход/выход, смена организации, отключение/возврат сети, установка, обновление панели, push. Не считать проверку локального уведомления проверкой доставки с сервера. Не выпускать до прохождения CI и ручной проверки на устройствах.
