# Изменения по выпускам

## 0.13.7

- В Android звуки по категориям открываются через шестерёнку в центре уведомлений. Застревания, наладка, общий чат наладчиков и освидетельствования имеют отдельные категории.
- Кружки в веб-панели и Android показывают только непрочитанное. Открытие системного push в Android отмечает прочитанным соответствующее событие.
- В наладке остаётся общий чат организации. Прежние чаты объектов скрыты, их переписки и файлы сохранены на сервере.

## 0.13.5

- Веб-панель и Android поддерживают ежедневные тихие часы, полные дни без push и режим «Только мои push».
- Расписание учитывает часовой пояс организации. Подавленные push не отправляются задним числом. Центр уведомлений сохраняет доступные события.

## 0.13.4

- «PDF для печати» в Android открывает журнал ТО за выбранный период.
- В чат объекта наладки и в комментарий при изменении готовности лифта можно прикрепить до пяти фотографий.
- Сообщения и комментарии пусконаладки появляются в центре уведомлений у пользователей с доступом. Системные уведомления Android используют FCM.

## 0.13.3

- Журнал ТО в карточке лифта, автоматическое заполнение по выполненным ТО и заявкам, печать по форме Мегаполиса.
- План ТО перенесён в карточку лифта.

## 0.13.2

- В веб-панели и Android при добавлении сотрудника администратор получает одноразовую ссылку на установку пароля. Ссылка действует 24 часа. Повторный выпуск заменяет предыдущую ссылку.
- Сотрудники с учётной записью по-прежнему присоединяются к другим организациям по коду приглашения.
- Боковое меню Android показывает все доступные разделы в одном списке с вертикальной прокруткой.

## 0.13.0 · кандидат на выпуск

- API, Web и Android используют общий номер 0.13.0. Android показывает установленную версию и номер сборки.
- Длительный ремонт с отдельным статусом, причиной и ожидаемой датой.
- Повторное редактирование будущих дежурств, фотографии и редактирование запчастей, связанные карточки в чате и диагностический экспорт.
- Пусконаладка с отдельным разрешением в карточке сотрудника, назначениями на лифты и приватными расходами. Android сохраняет прогресс, расходы с чеками и текст сообщений объекта в зашифрованной очереди.
- Открытые вложения и PDF сохраняются в зашифрованном кэше Android с лимитом 100, 500 или 1024 МБ. Кэш отделён от неотправленных файлов.
- Центр уведомлений, адресная рассылка заявок, отдельный сигнал застревания и предложение обновления Android из серверной папки. Автоматическая регистрация FCM после входа и разрешения в Android.
- PDF-журнал ТО получил титульный лист и таблицу по предоставленному Excel. Есть светлая, тёмная, системная и четыре цветовые темы.
- Серверный архив включает зависимости для PDF и проверяет миграции, файлы и версию API при обновлении.

[Состав, проверка и оставшиеся задачи 0.13.0](docs/RELEASE_STATUS_0.13.md).

## 0.12.0 · разработка (API / Web / Android)

- Единая версия **0.12.0** для Django API, веб-панели и Android APK; GitHub CI проверяет согласованность.
- Интегрирован черновой **LiftControl Push** как дополнительный HTTPS-канал к FCM, только при активном приложении; не заменяет полноценную фоновую доставку.
- Основа ветки содержит исправление повторного редактирования дежурств из 0.11.1.
- Остальные требования 0.12 и 0.13 выполняются отдельными задачами, **не помечены готовыми**.
- Добавлены API-модели и интерфейсы редактирования заказов запчастей, фотографий и связанных карточек в чате; при изменении одобренной заявки повторное согласование обязательно.
- Черновая автоматическая FCM-рассылка о новой проверенной APK (с защищённой очередью, отказом от дублей и проверкой действительного сеанса); Android показывает системное уведомление только при реально более новой версии. Требуются CI и проверка на телефоне.
- В меню «Ещё» Android и диагностике отображается версия **фактически установленной APK**, а не устаревшая строка 0.6.0-beta. Неизвестная версия не заменяется ложным номером 0.7.
- Исправлена нумерация подписанного Android 0.12: versionCode теперь начинается выше 2061; версия из метаданных выпуска соответствует AndroidManifest.
- Изменения не опубликованы на рабочем сервере. Подписанная APK не доступна без прежнего ключа.


## 0.11.1 / Android 0.6.1 beta · исправление в разработке

- [PR #14](https://github.com/sergeyviktorovich87/LiftControl/pull/14): Android позволяет повторно составить график и заменить будущие смены после подтверждения; можно изменить отдельного будущего дежурного.
- API сохраняет историю переназначения и защищает запросы подмены; веб-панель требует подтверждение при массовой замене.
- CI проверяет приложение без закрытого ключа. Подписанная APK выпускается только через защищённый GitHub workflow с прежним сертификатом.
- **Не выпущено:** нужен старый keystore, проверки и приёмка на телефоне и VPS. [Чек-лист](docs/HOTFIX_0.11.1.md).


## 0.11 · 13 ноября 2026

- Добавлена медиатека для вложений заявок, лифтов, чата и заданий. Файлы внутри организации переиспользуются, доступ проверяет API.
- В Android 0.6.0 beta добавлены зашифрованные вложения в очереди и повторная отправка после перезапуска без дублей.
- Установщик переносит старые медиа и создаёт полный архив базы и файлов. Проверено восстановление на отдельной базе.
- Сохранён механизм обновления Android из серверной папки и проверена подпись APK сборки 2061.
